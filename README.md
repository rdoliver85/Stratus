# Job Search Platform - Master's Thesis Project

Multi-source job aggregation platform built with Django and PostgreSQL, demonstrating advanced database design and API integration.

## Project Overview
This platform aggregates job listings from multiple sources (Adzuna, USAJobs, JSearch) into a unified search interface. Developed as a capstone project for Master of Science in Information Technology at Arkansas Tech University.

## Technology Stack
- **Backend**: Django 4.2, Python 3.12
- **Database**: PostgreSQL 15
- **Server**: Windows Server 2025 Datacenter
- **APIs**: Adzuna, USAJobs, JSearch (RapidAPI)
- **Caching**: Redis

## Features
- Multi-source job aggregation
- Advanced search with full-text indexing
- Geographic job search capabilities
- Intelligent duplicate detection
- Company profiles and job applications
